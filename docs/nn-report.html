How this was measured

  • Data: the dense core of the score matrix (372 models × 119 benchmark versions, 5248 measured scores). The split puts 298 models in training and 74 in validation; it is the same for every seed.
  • Held-out cells: the 141 validation scores hidden by seed 0's validation mask. The network sees each validation model's other measured scores. The site's estimates come from its pipeline rerun on a copy of the database without these scores.
  • The network never trains on validation models, but early stopping watches their loss, which includes these cells. Seed 0 stopped on exactly these cells hidden, so its numbers lean optimistic.
  • Seed changes initialization, training masks and validation masks; the split stays fixed.
